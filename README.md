# IMDB Movie Review Data Analysis

Through this project, the user can choose from many different ways to analyze the many movie reviews from a given dataset.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Make sure to import Pandas in Python
2. Make sure you have Python installed
3. Make sure you have the csv file of movie reviews

Instructions for using the software:

1. Save the file
2. Press play! Or run! 
3. Choose from the main menu how you want to analyze the data.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Pandas library
* Re library
* Latest version of Python
